# 标签接单协作平台 — 高保真原型 V2

## 启动

```bash
cd docs/原型设计/prototype
npm install && npm run dev
# → http://localhost:5173/
```

## 页面总览（23 个路由）

### 通用
| 页面 | 路由 |
|------|------|
| 登录（含角色快捷切换） | `/` |

### 品牌方（8 页）
| 页面 | 路由 | 核心交互 |
|------|------|----------|
| 工作台 | `/brand/dashboard` | 统计卡片（可点击跳转）+ 最近订单 |
| 模板管理 | `/brand/templates` | 表格+类型筛选+搜索+编辑/复制 |
| 创建订单 | `/brand/order-create` | 5 步向导：选类型→匹配模板→填数量(含Excel导入区)→收货信息→确认提交 |
| 订单列表 | `/brand/orders` | 状态/类型筛选+日期范围+导出Excel+点击跳详情 |
| 订单详情 | `/brand/orders/:id` | 完整信息+子订单生产进度表+**取消订单弹窗**+**砍单弹窗**(校验已生产数量) |
| 工厂管理 | `/brand/factories` | 表格+新增+编辑+停用 |
| 对账管理 | `/brand/billings` | 账期筛选+确认+导出Excel+下载发票 |

### 平台运营（6 页）
| 页面 | 路由 | 核心交互 |
|------|------|----------|
| 工作台 | `/ops/dashboard` | 统计卡片+最新待审核(可点击) |
| 订单管理 | `/ops/audit` | 审核列表→详情弹窗(含收货信息+模板+图稿)→**通过→拆单转单弹窗**(供应商分配+数量实时校验+发送通知) |
| 品牌管理 | `/ops/brands` | 表格+新增+EPC规则入口+停用 |
| 供应商管理 | `/ops/suppliers` | 表格+新增+停用 |
| EPC规则配置 | `/ops/epc-rules` | 按品牌查看+新增/编辑/停用规则(SGTIN-96/自定义流水号) |
| 供应商对账 | `/ops/billings` | 账期筛选+确认付款 |

### 供应商（8 页）
| 页面 | 路由 | 核心交互 |
|------|------|----------|
| 工作台 | `/supplier/dashboard` | 统计卡片+最新待接单 |
| 订单列表 | `/supplier/orders` | 状态筛选+日期范围+跳详情 |
| 订单详情与接单 | `/supplier/detail` | 订单信息+**图稿预览区**+核对清单(checkbox)+确认接单/反馈异常弹窗 |
| EPC数据上传 | `/supplier/epc` | 拖拽上传→模拟校验→通过/异常统计+**异常明细表格**(行号+EPC+重码/错码标签+导出xlsx)+红色警告 |
| 发货管理 | `/supplier/shipment` | 发货表单(数量校验不超待发)+发货记录表格(批次号+物流+签收状态) |
| 送货单 | `/supplier/delivery-note` | 标准化送货单预览+下载PDF/打印 |
| 包装贴下载 | `/supplier/labels` | 小包贴/中包贴/箱贴下载 |
| 对账管理 | `/supplier/billings` | 账期筛选+确认+上传发票 |

## 跨页面跳转链路

- Dashboard 统计卡片 → 对应列表页
- 订单列表 → 订单详情
- 订单详情 → 返回列表 / 取消订单 / 砍单
- 审核列表 → 审核弹窗 → 拆单弹窗
- 品牌管理 → EPC规则配置
- 供应商订单列表 → 订单详情 → EPC上传 → 发货

## 技术栈

React 18 + TypeScript + Ant Design 5 + React Router 6 + Vite 8
