# 标签接单协作平台 — 产品需求规格 V1

## 一、项目概述

### 1.1 平台定位

独立的标签接单协作平台，串联 **品牌方 → 平台方 → 下游供应商** 三方，覆盖从标签下单到交付验收的全流程管控。不是简单的数据传输工具，而是业务协作系统。

### 1.2 核心价值

- 消除邮件/微信手工传递 Excel 和图稿的低效与出错风险
- 实现订单状态全程可追踪
- 数据闭环：EPC/TID 从生产到交付全链路打通，品牌内全局唯一性校验
- 为引入小厂合作提供系统化保障

### 1.3 三方角色

| 角色 | 职责 |
|------|------|
| **品牌方** | 提交标签订单、维护模板、确认对账付款 |
| **平台方（内部接单管理）** | 审核订单、拆分转单、协调供应商、品控 |
| **下游供应商（标签生产商）** | 接单生产、上传生产数据、发货、对账 |

---

## 二、账号体系

### 2.1 账号类型

| 账号类型 | 说明 |
|----------|------|
| 客户公司 | 实际业务客户主体，可运营多个品牌。平台方创建客户公司时可配置 `allow_brand_switch`。 |
| 品牌方管理员 | 挂靠在客户公司下某个品牌，管理该品牌的模板、订单、工厂。若客户公司开启了品牌切换，可在多个品牌间切换操作。 |
| 成衣工厂子账号 | 挂靠在品牌下，可独立下单，数据汇总至品牌(平台方可配置是否汇总) |
| 内部接单管理账号 | 平台方运营人员，负责审核、转单、异常处理 |
| 下游供应商账号 | 标签生产商，接单、生产、发货、对账 |

### 2.2 多工厂挂靠与多品牌架构

```
客户公司
├── 品牌A
│   ├── 工厂1
│   └── 工厂2（可能多达几十上百个）
├── 品牌B
│   └── 工厂3
```

- 一个客户公司下可挂靠多个品牌
- 一个品牌下可挂靠多个成衣工厂账号（可能多达几十上百个）
- 每个工厂可独立采购下单
- 订单数据统一汇总到品牌（平台方可配置是否汇总到主账号）
- 对账、开票、回款流程均按独立工厂维度处理，同时支持按品牌、按客户公司汇总
- 品牌方用户是否可在品牌间切换，由平台方通过客户公司的 `allow_brand_switch` 开关控制

---

## 三、订单类型

| 类型 | 说明 | 适用范围 |
|------|------|----------|
| **大货单** | 正常生产订单，SKU + 数量 | 所有客户通用 |
| **免费单** | 金额为 0，补偿客户短装损耗。品牌方不可选，由平台方在审核环节标记 | 例如骆驼有这种场景 |
| **补单** | 分两种：商家自身生产损耗补发 / 客户临时追加产量 | 所有客户 |

**免费单规则**：品牌方下单时仅可选「大货单」或「补单」；平台运营人员可在审核/接单环节将订单标记为「免费单」。免费单走完整下单流程，仅出对账单时价格记为 0，不走特殊通道。

---

## 四、核心业务流程

```
品牌方下单 → 平台接单审核 → 拆单转单(通知供应商) → 供应商生产 → 发货 → 签收 → 对账回款
                                    ↕
                              订单取消 / 砍单（逆向）
```

---

## 五、品牌方下单（两种路径）

### 5.1 路径一：预维护模板（标准路径）

**前置条件**：品牌方提前在系统维护好模板（吊牌标签、不干胶贴纸标签、洗麦标签）

1. 品牌方登录，选择模板类型
2. 系统自动匹配对应模板
3. 品牌方可手动修改模板内容
4. 填写收货信息（收货地址、联系人、联系电话）
5. 确认后提交订单
6. 订单推送至内部接单账号，短信/邮件通知

### 5.2 路径二：即时生成模板

**适用场景**：品牌方没有预维护模板

1. 品牌方采购提交 SKU + 数量 + 收货信息
2. 品牌方内部打单员根据 SKU 信息即时创建模板
3. 填写内容：品名、执行标准、尺码、洗涤方式 等
4. 模板确认后推送订单

### 5.3 补单规则

- 同 SKU 补单时，系统自动匹配该 SKU 最新模板
- 支持品牌方修改模板后重新上传
- 无需重复创建模板

### 5.4 核心数据要求

品牌方下单时必须提供：**SKU 对应标签需求数量**（整个订单流程的核心数据）

## 六、平台方接单与转单

### 6.1 订单审核

- 内部接单管理账号收到新订单通知（短信/邮件）
- 审核订单信息和图稿

### 6.2 拆单转单

- 大订单可拆分为多个子订单，分配给不同下游供应商
- 例：200 万订单拆分给 5 家供应商各 40 万
- 拆分后每个供应商对应独立子订单，独立处理生产和发货
- 转单后供应商收到短信/邮件通知，可第一时间登录查看

### 6.3 EPC 数据包生成

- 品牌方接入系统时预先维护该品牌的 EPC 生成规则（可多条）
- 接单并审核画稿后，系统根据预设规则自动生成对应 SKU 的 EPC 数据包
- 数据包含：SKU、数量、商品名称、网址、EPC 等信息
- 一次性同步给对应供应商，无需二次发送

---

## 七、供应商生产流程

### 7.1 接单与对稿

1. 供应商登录，查看已分配订单
2. 在线预览订单图稿
3. 核对信息：品名、字号、打印位置 等
4. 核对无误 → 确认开始生产
5. 有异常 → 在线反馈

### 7.2 生产数据上传

供应商生产完成后需上传：

| 数据类型 | 说明 |
|----------|------|
| EPC 数据 | 电子标签唯一编码 |
| TID 数据 | 标签标识符 |
| 二维码数据 | 固定防伪域名 + EPC 变量 |

### 7.3 数据校验

- 系统自动校验是否存在 **重码（品牌内全局唯一，含历史数据）、错码**（红线）
- 异常自动报警，通知停止生产

### 7.4 生产打包

- 供应商设备端设置复合校验环节，每过一个 EPC 自动计数
- 发现问题自动停机，人工剔除不合格品
- 可设定每包打包数量（如 100 张/包），达到数量自动停机
- 工人打包完成后点击继续，设备继续生产下一包
- 一般按 SKU 分包，一个 SKU 对应一个或多个小包，支持调整打包数量

---

## 八、EPC 编码规则

### 8.1 规则类型

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| **SGTIN-96 可解析编码** | 通过 3034、3035 等标识反解析 SKU 信息，依托商品信息生成 | 新货期货订单 |
| **自定义流水号编码** | 按品牌自定义流水号，格式如 A001、A002 | 存量标签补货 |

### 8.2 配置与规则

- 每个品牌方接入时预先维护 EPC 生成规则（一个品牌可维护多条规则）
- 两种规则可在同一品牌方同时存在
- 规则选择与订单类型相关：
  - 补货订单 → 流水号规则（生成更快）
  - 新货订单 → 可解析规则

---

## 九、发货与物流

### 9.1 发货数据回传

- 供应商发货时填写：已发数量、快递单号
- 系统自动生成批次流水号
- 支持 **分批发货**，显示部分发货状态

### 9.2 签收方案

| 方案 | 说明 |
|------|------|
| 电子回单上传 | 工厂上传电子签收单完成签收 |
| 默认自动收货 | 不需要电子回签时，系统自动确认收货 |

**决策依据**：纸质签收单快递返回成本 5-8 元/张，默认方案以降成本优先。若不需要电子签收，以对账单确认为准，确认对账单即视为完成收货。

---

## 十、包装贴与送货单

### 10.1 包装贴

- 预设模板：小包贴、中包贴、箱贴
- 内容：SKU、款号、颜色、尺码、数量
- 供应商在线下载打印，直接对接本地打印机输出不干胶贴

### 10.2 送货单

- 供应商可直接在系统生成关联对应采购订单的送货单
- 满足发货交付的标准化要求

**价值**：降低供应商自行开发小工具的成本，优化报价空间。

---

## 十一、对账与回款

### 11.1 对账单生成（品牌方方向）

- 按 **客户 + 时间段** 自动生成对账单（支持按工厂、按品牌、按客户公司三个维度，详见 11.4）
- 包含字段：SKU、数量、单价、发货时间、快递单号
- 支持导出 Excel

### 11.2 发票与账期管理

- 客户确认对账单后，可上传对应发票
- 系统按约定账期自动预警
- **超期未付款 → 限制新订单发货**
- 对账、开票、回款均按独立工厂维度处理

### 11.3 供应商方向对账（镜像逻辑）

- 供应商生成对账单
- 内部确认后安排付款
- 系统维护付款状态
- 逻辑与品牌方方向一致，方向相反

### 11.4 对账单聚合维度

对账单支持三个维度的聚合：

| 维度 | 说明 | 使用场景 |
|------|------|----------|
| 按工厂 | 单工厂已签收子订单汇总 | 工厂独立核算 |
| 按品牌 | 品牌下所有工厂汇总 | 品牌整体对账 |
| 按客户公司 | 客户公司下所有品牌汇总 | 集团级对账 |

系统默认按工厂维度生成对账单，品牌方可在对账页面切换聚合维度。

---

## 十二、逆向流程

### 12.1 订单取消

- 品牌方因业务变更或信息填错，全程取消整笔订单
- **特殊规则**：品牌可配置允许生产后取消，已生产标签由商家另行处置
- 不同品牌对取消节点约定不同，系统需支持配置

### 12.2 砍单

- 品牌方仅减少订单生产数量，不取消整单
- **财务规则**：已生产完成并准备发出的部分，出对账单时按已发出状态统计金额，由品牌方承担已生产费用

---

## 十三、系统对接拓展

### 13.1 设备接口对接

- 供应商生产设备调用系统接口
- 设备端生产完成点击确认 → EPC、TID 等生产数据自动实时上传
- 无需手动导入

### 13.2 预留拓展

- **小包 EPC 清单**：记录每个小包内包含的具体 EPC 清单
- 暂无客户能提供现成的 EPC 和 TID 绑定模型，后续开发
